## Why does this fork exist?

Personal experimentation and study only. It exists so a single maintainer can
read, run, and modify the code freely without affecting the upstream project.

## Relationship to upstream

- Created via GitHub's native **fork** feature. The upstream link is preserved,
  so GitHub's **Sync fork** button works normally.
- `master` is kept as a **pristine mirror** of upstream `master`. No code
  changes are made here.
- This file is the only file added on top of upstream, which is why upstream
  syncs never conflict.
- Synced **manually**. Last sync is listed in the pinned issue at the top of
  this repository's Issues page.
